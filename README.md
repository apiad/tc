# The Transcendent Chronicles

A science-fiction worldbuilding project — thirteen thousand years of human
history after Earth. Published at **https://apiad.github.io/tc**

Earth is dying. In the twenty-second century it launches hundreds of Genesis
seedships toward every star within reach, each carrying frozen embryos and a
guardian intelligence with the whole of human knowledge aboard. Each ship
raises a first generation, seeds a colony, and goes to sleep. Thirteen thousand
years later their children have forgotten Earth, rediscovered each other, built
an empire, and lost it.

## About this repository

This repo is **generated**. The source of truth lives in a private vault; the
content here is produced by an export gate that publishes only material
explicitly marked as publishable. Do not edit `chronicles/` or `encyclopedia/`
by hand — changes there are overwritten on the next export.

Built with [Quarto](https://quarto.org). `quarto render` writes `docs/`, which
GitHub Pages serves.
